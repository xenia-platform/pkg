Xenia pkg repository

The xenia-server package for FreeBSD 14 and 15, amd64 and arm64, signed by the RSA key xenia.pub. As root, to add it and install xenia:

mkdir -p /usr/local/etc/pkg/keys /usr/local/etc/pkg/repos
fetch -o /usr/local/etc/pkg/keys/xenia.pub https://xenia-platform.github.io/pkg/xenia.pub
printf 'xenia: {\n  url: "https://xenia-platform.github.io/pkg/${ABI}",\n  signature_type: "pubkey",\n  pubkey: "/usr/local/etc/pkg/keys/xenia.pub",\n  enabled: yes\n}\n' \
  > /usr/local/etc/pkg/repos/xenia.conf
pkg update -r xenia && pkg install -y -r xenia xenia-server
sysrc xenia_enable=YES && service xenia start

Upgrades come with pkg upgrade; it stops the service, so start it again after. Deployment says what the package sets up.
